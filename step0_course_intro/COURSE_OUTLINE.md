# 課程大綱（六步一覽）

主線一句話：**上一堂課你的裝備物資模組是假資料（F5 就消失）；這堂課把它變真的——AI＋範本＋harness 生出 .NET API 與 PostgreSQL 資料表，前端切一個開關，資料就永久保存。**

| Step | 白話說這步在幹嘛 | 你會產出／帶走什麼 | 時間 |
|------|------------------|--------------------|:---:|
| **step0** 課程說明 | 搞懂這門課要把你帶到哪、先把機器準備好（.NET／PostgreSQL／埠號）。 | 一台通過 11 項 preflight 的機器。 | 10 分 |
| **step1** 為什麼要 harness | 同一句後端需求，看「有 harness」和「沒 harness」生出來的 API 差多少——體會規矩的價值。 | 一組對比 demo 的心得：差異來自六條鐵律＋範本＋系統文件。 | 10 分 |
| **step2** 快速完工秘笈 | 把「後端速通包」玩過一輪：跑範本 API、讀 SRS/SDD、看 harness 四件、看懂分層架構與 DB 綱要。 | 一支能跑的範本 API（人員 CRUD，49 測試綠）＋一份看得懂的系統文件與規則。 | 35 分 |
| **step3** 複製範本開發新模組 | 拿真實 PRD（中心裝備物資），讓 AI 先用選擇題釐清範圍，再生 SRS/SDD delta、API、Migration、測試。 | 一支裝備物資 API（含資料表、種子 24 筆、測試）＋一份自己回答過的 SCOPE 選擇題。 | 40 分 |
| **step4** LOOP＋全鏈路 E2E | 注入一個後端 bug 讓測試變紅，練「判因→修→綠」；再把現成前端切到真後端，跑一次全鏈路 E2E。 | 一次紅轉綠的實作經驗＋一個「切開關資料就進資料庫」的全鏈路實證。 | 20 分 |
| **step5** 課程總結 | 回顧整條主線、對照評量量表、想清楚回公司怎麼落地。 | 一張自評量表（RUBRIC）＋回公司可複製的做法。 | 5 分 |

> step2 內再分 2.1～2.5（玩範本 → 系統文件 → harness 四件 → 分層架構＋DB → 範本程式），照順序做。
> 時間為**目標**分配，非承諾；請照 step0 → step5 順序走，不要跳步。
