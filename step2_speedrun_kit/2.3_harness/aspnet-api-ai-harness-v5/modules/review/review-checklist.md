# 通用系統規範檢查清單

不需要 SPEC 也能判斷的業界慣例。缺項預設 ⚠️；影響資料正確性或安全時升 ❌。

## 清單頁

- [ ] 搜尋 / 篩選 / 排序
- [ ] 分頁：顯示「第 N 頁，共 N 筆」；props 有預設值，不出現 NaN
- [ ] 空狀態畫面、載入中狀態
- [ ] 新增按鈕、操作欄
- [ ] 表格內操作按鈕用次要樣式（outline / ghost），不用 solid

## 表單頁

- [ ] 必填欄位有 `*` 標記
- [ ] 驗證錯誤有文字訊息，不能只有紅框
- [ ] 儲存為 primary；危險操作二次確認
- [ ] 送出後有 Toast 回饋；送出中顯示 loading 並防止重複送出
- [ ] Label 在欄位上方，不用 placeholder 取代 label

## 詳情頁

- [ ] 返回鍵
- [ ] 審計欄位（建立 / 修改時間與操作人）
- [ ] 狀態 badge、編輯入口

## Modal / Dialog

- [ ] 確認按鈕文字寫明動作（「刪除設備」而非「確認」）
- [ ] 危險操作用 error 色
- [ ] 可 Esc / 點外部關閉

## API / 後端

- [ ] 無 SQL Injection（參數化查詢）
- [ ] 無明文密碼 / secrets（用占位符或設定管理）
- [ ] 日誌（含例外堆疊）不輸出個資與敏感資料
- [ ] 未實作端點回 `501`，不回假 `200`
- [ ] 錯誤回應格式與既有 envelope 一致
- [ ] 權限檢查存在且對應角色

## 流程

- [ ] 條件顯示順序合理（先選父層才選子層）
- [ ] 未儲存離開有 dirty check，或明確標示不需要
- [ ] 不可逆操作有警告
- [ ] 時間格式統一（如 `YYYY/MM/DD HH:mm`）、金額千分位
