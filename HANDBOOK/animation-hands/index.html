文字版速查

這一支是手把手版（跟著做）：只講點哪裡、貼哪一段、看到什麼就對了。想知道為什麼這樣做，看講課版。建議左邊開動畫、右邊開 VS Code，看完一段就暫停、自己做一次。手冊沒有複製按鈕：在黑底框裡反白、按 Ctrl+C。

動畫裡的畫面，都是 2026-10-07 在 Windows 11 實際操作時拍下來的：VS Code（繁體中文介面）、Claude Code 擴充、PowerShell 終端機、Chrome（Swagger）、psql。大字版終端機裡的每一行，也都是同一次操作印出來的真實文字。

配音由 Google Gemini 3.8 Flash TTS 預先錄好：阿哲帶你一步一步操作，小芸講檢查點和卡住時怎麼辦。聲音全部是預錄好的 mp3 檔，播放時不用連 AI、不花 token，也不用瀏覽器內建的語音。動畫裡的指令只放在畫面字卡，完整指令看下面和手冊。

Step 3 用 SDD 叫 AI 做新模組

  • 用瀏覽器開圖（在 my-equipment-api 的終端機）：start docs\DIAGRAMS-裝備物資API.html
  • AI 問下一步：文件出來後選「我先看文件」；做完後選「我先驗收」；全部沒問題打「驗收通過」
  • 教材根目錄整段貼上手冊 step3 的複製指令（Copy-Item 三行＋cd），出現 >> 後再按 Enter
  • 「檔案」→「開啟資料夾」→ step3_new_module\my-equipment-api
  • 右下角「✻ Claude Code」→ 模型選 Opus 5.5、effort High → 貼起手 prompt（4 行）→ 送出
  • 選擇題先自己答，每題看 AI 寫的理由和代價再選；講師會在你答完後發課堂裁決，再對照一次。AI 追加的題目，看不懂就選它標「建議」的
  • AI 先交 docs 裡的 SRS-delta、DESIGN-delta、DIAGRAMS、TASKS 四個檔。圖用瀏覽器開 docs\DIAGRAMS-裝備物資API.html
  • 說「開工」之前，把模型切成 Sonnet 5.5（有規矩和範本，寫程式不用最貴的模型）
  • 三路驗收：Swagger 五路由（http://localhost:5080/swagger）、dotnet test 全綠、psql 查 ai_crud_equipment 的 equipment_item 24 列。有小落差就一次講一件：看到什麼、期望什麼

  • 測試報告：start step4_loop_e2e\e2e\playwright-report\index.html

  • 開新的 Claude Code 對話（模型 Sonnet 5.5），貼手冊的 LOOP prompt（4 行；鐵律和產出都寫在 step4_loop_e2e/LOOP-規矩.md）
  • AI 自己啟動受測 API（5080）和前端（3199），埠被占就自己換；跑 run-e2e 修到 6 條全綠；再開一個 Opus 5.5 的子代理，先用 HTTP 實打 API，再用 Playwright 開瀏覽器截圖做對抗審查
  • 四樣產出：my-equipment-api/loop/LOOP-REPORT.html（給人看的報告，結論在最前面、有截圖，一定看）、step4_loop_e2e/e2e/playwright-report/index.html（測試報告，一定看）、SRS-delta／DESIGN-delta／DIAGRAMS 有沒有標「step4 LOOP 後」（一定看）；loop/LOOP-LOG.md 是流水紀錄，有紅燈時才翻

卡住時

  • 一執行 .\preflight.ps1 就出現「已停用指令碼執行」或「未經數位簽署」：先執行 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned，再重跑。公司電腦不准改這個設定時，找 IT 或講師。
  • preflight 說 PostgreSQL 連不上或帳密不對：這是後端課的命脈。先 Get-Service postgresql* 看服務有沒有在跑，停著就 Start-Service postgresql-x64-18；密碼不是 12345 就照手冊 Step 0 改回來。還是紅，整段輸出貼給 AI。
  • 找不到 psql：不用加 PATH。preflight 會印出完整路徑（通常是 C:\Program Files\PostgreSQL\18\bin\psql.exe），指令前面加 &、路徑用引號包起來。
  • dotnet run 說 5080 被占用：多半是上一個 API 還在跑。回那個終端機按 Ctrl+C；不確定是誰在用，就換一個埠 --urls http://localhost:5081，Swagger 網址跟著改。LOOP 的 AI 也會自己換埠。
  • dotnet 第一次跑很慢：它在下載套件，課前先跑一次 dotnet run 和 run-e2e，別留到上課。
  • dotnet build 噴紅字：從你打的指令那一行開始整段複製，貼給 AI；同一個錯誤修兩次還不行，找講師。
  • AI 問你要不要連上你自己的 Chrome（Claude in Chrome 之類的擴充）：這門課用不到，選「No」，跟它說「不用連我的瀏覽器，繼續」。Step 4 的 Playwright 不一樣：那是 AI 自己開的測試瀏覽器，用來截圖驗收，讓它跑，不要擋。
  • Step 3 時間不夠：講師有 checkpoint 腳本，可以直接套參考解，跟上三路驗收和 Step 4。
